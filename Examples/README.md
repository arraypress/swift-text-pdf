# Examples

What the writer can put on a page, as PDFs you can open before installing anything.

These are the primitives rather than finished documents — this package is the framework, and [swift-invoice-pdf](https://github.com/arraypress/swift-invoice-pdf) and [swift-resume-pdf](https://github.com/arraypress/swift-resume-pdf) are what finished documents look like. Somebody evaluating this is deciding whether the page will hold what they need, and a feature list does not answer that.

Generated by the writer itself — `WRITE_EXAMPLES=1 swift test --filter ExampleTests` — so none of them can drift from what the code produces, and every one is proved to render on each test run.

| | |
|---|---|
| [tables](tables.pdf) | Proportional columns, alignment, striping, a total row, measured truncation |
| [multi-page](multi-page.pdf) | A table breaking across pages, the header repeating, the footer knowing the final count |
| [curves](curves.pdf) | Circles, rings, arcs, rounded rectangles and meters, from Béziers rather than approximated |
| [vector-path](vector-path.pdf) | One SVG path stamped at four scales — zoom in, the edges stay sharp |
| [typography](typography.pdf) | The base-14 fonts, and an embedded family in four weights and an italic beside them |
| [justified](justified.pdf) | The same paragraph ragged and justified, side by side |
| [beyond-latin1](beyond-latin1.pdf) | Cyrillic, Greek and CJK with a fallback face and without |
| [pictures](pictures.pdf) | A JPEG passed through undecoded, a PNG with its transparency intact, both over a tint |
| [links](links.pdf) | Clickable text — an annotation measured against the run it covers |
| [watermarks](watermarks.pdf) | DRAFT behind the content, and the alpha and rotation it is made of |
| [qr](qr.pdf) | An EPC payment payload at three sizes and four correction levels |
| [bookmarks](bookmarks.pdf) | Three pages with an outline — open the sidebar |
| [attachments](attachments.pdf) | An XML file carried inside the PDF, which is what an e-invoice is |
